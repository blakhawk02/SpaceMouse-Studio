# SpaceMouse Studio Bridge 0.1.0-beta.1

Initial public beta of the Windows companion bridge for the separately installed SpaceMouse Studio Roblox Studio plugin.

## Included

- Normalized six-axis SpaceMouse input over localhost only.
- Windows x64 self-contained bridge executable.
- Loopback binding on `127.0.0.1:37567`.
- No telemetry or outbound network access.
- Proprietary Beta License and installation instructions included in the ZIP.

## Install

Download `SpaceMouse-Studio-Bridge-Windows-x64.zip`, extract the complete ZIP, and run `bridge\SpaceMouseStudioBridge.exe`.

This beta is not code-signed, so Windows may show an Unknown Publisher or SmartScreen warning.
